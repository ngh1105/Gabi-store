## Slide 2: Đặt vấn đề & Mục tiêu
### Tại sao chọn đề tài này?
*   Nhu cầu mua sắm trực tuyến ngày càng tăng cao.
*   Cần một hệ thống bán hàng chuyên nghiệp, giao diện đẹp, dễ sử dụng.
*   Áp dụng các công nghệ mới (ReactJS, NestJS) vào thực tế.

### Mục tiêu dự án
1.  Xây dựng website bán hàng đầy đủ tính năng.
2.  Tối ưu hóa trải nghiệm người dùng (UX/UI).
3.  Hệ thống quản lý dữ liệu hiệu quả, bảo mật.

---

## Slide 3: Công nghệ sử dụng (Tech Stack)
### Frontend (Client-side)
*   **ReactJS 18:** Component-based, SPA.
*   **Redux Toolkit:** Quản lý State tập trung.
*   **Tailwind CSS + Flowbite:** Thiết kế giao diện hiện đại, Responsive.
*   **Các thư viện khác:** Axios, Formik, React-Router.

### Backend (Server-side)
*   **NestJS:** Framework Node.js kiến trúc module, chuẩn doanh nghiệp.
*   **MySQL:** Cơ sở dữ liệu quan hệ, lưu trữ đơn hàng, sản phẩm.
*   **Sequelize ORM:** Tương tác database an toàn, dễ dàng.
*   **JWT:** Xác thực bảo mật.

## Slide 4: Tổng quan kiến trúc hệ thống
*(Chèn hình sơ đồ High-level Architecture tại đây)*
